# Keyboard Shortcuts

Speed up your workflow with these keyboard shortcuts.

## Global Shortcuts

| Shortcut | Action |
|----------|--------|
| `?` | Show keyboard shortcuts reference |
| `Ctrl/Cmd + K` | Open global search |
| `Ctrl/Cmd + /` | Toggle sidebar |
| `Ctrl/Cmd + B` | Toggle sidebar |
| `Ctrl/Cmd + ,` | Open settings |
| `Esc` | Close modal or dialog |

## Navigation

| Shortcut | Action |
|----------|--------|
| `G` then `D` | Go to Dashboard |
| `G` then `C` | Go to Components |
| `G` then `T` | Go to Topics |
| `G` then `O` | Go to Operations |
| `G` then `P` | Go to Parameters |
| `G` then `F` | Go to Faults |
| `G` then `V` | Go to Visualizations |
| `G` then `M` | Go to Performance |
| `G` then `S` | Go to Settings |

## Theme and Display

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + Shift + L` | Toggle light/dark theme |
| `F11` | Toggle fullscreen |

## Data Operations

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + R` | Refresh current view |
| `Ctrl/Cmd + E` | Export current data |
| `Ctrl/Cmd + S` | Save configuration |

## Topic Viewer

| Shortcut | Action |
|----------|--------|
| `Space` | Pause/resume auto-refresh |
| `Ctrl/Cmd + C` | Copy topic data to clipboard |
| `Ctrl/Cmd + F` | Search within JSON data |

## Component Browser

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + F` | Focus search input |
| `↑` / `↓` | Navigate component list |
| `Enter` | Open selected component |
| `Backspace` | Go back to component list |

## Fault Monitor

| Shortcut | Action |
|----------|--------|
| `Ctrl/Cmd + F` | Filter faults |
| `E` | Show only errors |
| `W` | Show only warnings |
| `A` | Show all faults |

## Visualizations

| Shortcut | Action |
|----------|--------|
| `R` | Reset camera view |
| `L` | Toggle layer visibility |
| `+` / `-` | Zoom in/out |
| `Arrow keys` | Pan view |

## Accessibility

| Shortcut | Action |
|----------|--------|
| `Tab` | Navigate to next interactive element |
| `Shift + Tab` | Navigate to previous interactive element |
| `Enter` / `Space` | Activate focused element |

## Tips

- Most shortcuts work globally, but some are context-specific
- Shortcuts are case-insensitive unless specified
- On macOS, use `Cmd` instead of `Ctrl`
- Press `?` anytime to see this reference

## Customization

You can customize keyboard shortcuts in **Settings > Keyboard Shortcuts** (coming soon).
