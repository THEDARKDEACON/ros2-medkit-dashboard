# Quick Start Guide

Welcome to the Dojo Robot Web Dashboard! This guide will help you get started quickly.

## Getting Started

### 1. Connect to Your Robot

1. Click the **Robot Selector** dropdown in the top-right corner
2. Click **Add Robot** to configure a new robot connection
3. Enter your robot's name and API URL (e.g., `http://localhost:8080`)
4. Click **Save** to connect

The connection status indicator will show green when connected.

### 2. Navigate the Dashboard

Use the sidebar on the left to access different sections:

- **Dashboard**: System health overview and quick access cards
- **Components**: Browse robot components organized by areas
- **Topics**: Monitor real-time topic data streams
- **Operations**: Execute services and actions
- **Parameters**: View and modify configuration parameters
- **Faults**: Monitor system faults and diagnostics
- **Visualizations**: View 2D maps and 3D point clouds
- **Performance**: Monitor system resource usage

### 3. Monitor Your Robot

The **Dashboard** page provides an at-a-glance view of your robot's status:

- System health indicator
- Active component count
- Fault summary
- Quick access to key subsystems

### 4. View Component Details

1. Navigate to **Components** in the sidebar
2. Browse areas and expand to see components
3. Click on a component to view its details
4. Use tabs to switch between Topics, Operations, and Parameters

### 5. Monitor Topic Data

1. Select a component from the Components page
2. Click the **Topics** tab
3. Click on a topic to view its real-time data
4. Use the JSON inspector to explore message structure
5. Adjust refresh rate using the controls

### 6. Execute Operations

1. Navigate to a component's **Operations** tab
2. Select a service or action from the list
3. Fill in required parameters
4. Click **Execute** to run the operation
5. For actions, monitor progress in real-time

### 7. Modify Parameters

1. Navigate to a component's **Parameters** tab
2. Find the parameter you want to modify
3. Click the edit icon or double-click the value
4. Enter the new value
5. Press Enter or click Save to apply changes

### 8. Customize Your Layout

1. Navigate to **Settings**
2. Choose from preset layouts (Operator, Developer, Researcher)
3. Or create a custom layout by dragging and resizing panels
4. Your layout preferences are saved automatically
